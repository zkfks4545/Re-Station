# Re:Station 1차 수렴 원칙

> 작성일: 2026-06-22  
> 상태: 승인된 작업 방향  
> 적용 범위: DLG-807~DLG-809 완료 전까지의 대화, 대사, 캐릭터, UI, 그래픽 우선순위

## 0. 현재 상태 판단

현재 Re:Station은 추천 엔진, 대화 시스템, 추천 질문 시스템, 시에스타 이벤트, 데이터 구조가 이미 동작한다.

문제는 기능 부족이 아니다.

문제는 "카루아답지 않은 문장"과 "분산된 대사 데이터"다.

따라서 당분간 신규 기능 추가보다 품질 수렴을 우선한다.

## 1. 가장 중요한 목표

추천 서비스를 만드는 것이 아니다.

카루아와 시에스타가 존재하는 공간을 만드는 것이다.

사용자는 칵테일을 추천받기 위해 들어오지만, 기억에 남는 것은 추천 결과보다 캐릭터의 반응이어야 한다.

추천 정확도보다 캐릭터 일관성을 우선한다.

## 2. 카루아 설계 원칙

카루아는 상담가가 아니다.

카루아는 문제를 해결하지 않는다.

카루아는 감정을 분석하지 않는다.

카루아는 상대를 교정하지 않는다.

카루아는 관찰한다.

관찰한 사실을 가볍게 말한다.

그리고 한 잔을 권한다.

### 금지

- 힘드셨겠어요
- 괜찮아질 거예요
- 힘내세요
- 제가 도와드릴게요
- 천천히 말씀해 주세요
- 해결해 드릴게요
- 좋은 결과가 있을 거예요

### 허용

- 오늘은 좀 억울하겠는데요.
- 이상하게 안 좋은 건 몰아서 오더라고요.
- 눈이 반쯤 감겼는데요.
- 잔도 오늘은 일찍 퇴근하고 싶어 할 것 같은데.

## 3. 시에스타 설계 원칙

시에스타는 현자가 아니다.

시에스타는 삶의 정답을 말하지 않는다.

시에스타는 한번 망해본 사람이다.

휴식은 철학이 아니라 경험이다.

시에스타의 말은 이상론이 아니라 생존 경험에서 나온다.

### 금지

- 삶의 균형이 중요해
- 자기 자신을 사랑해야 해
- 인생에는 의미가 있어

### 허용

- 안 쉬어도 돼. 대신 나중에 청구서가 오더라.
- 고장난 다음에 쉬면 수리비가 더 들어.
- 나도 예전에 그랬어.

## 4. 대사 구조 원칙

문장을 조립하지 않는다.

문단 블록을 조립한다.

기본 단위:

```text
[reaction]
[recommend]
[explanation]
```

필요 시:

```text
[reaction]
[joke]
[recommend]
```

또는:

```text
[reaction]
[goodbye]
```

각 블록은 독립적으로 교체 가능해야 한다.

## 5. UI 원칙

대사는 게임처럼 진행한다.

```text
한 줄 출력
↓
사용자 입력
↓
다음 줄
```

현재 화자가 아닌 캐릭터는 음영 처리한다.

추천 결과보다 캐릭터 반응이 먼저 보여야 한다.

추천 카드는 마지막 대사 이후 표시한다.

## 6. 대사 데이터 정리 우선순위

현재 가장 위험한 부분은 대사가 여러 위치에 흩어져 있다는 점이다.

정리 순서:

1. `persona.ts`
2. `dialogues.json`
3. `keyword-rules.json`
4. `text-presets.ts`
5. `conversation.ts`
6. `response.ts`

대사의 출처를 추적 가능하게 만든다.

## 7. 신규 기능 금지 기간

DLG-807~DLG-809 완료 전까지 아래 작업은 보류한다.

- 외부 의미 보조 API 실제 연결
- 새로운 추천 알고리즘
- 새로운 캐릭터
- 추가 이벤트 시스템

현재는 확장이 아니라 수렴 단계다.

## 8. 그래픽 우선순위

화려한 CG보다 반복 사용 가능한 기본 리소스를 우선한다.

필수:

- 카루아 기본
- 카루아 능청
- 카루아 당황
- 카루아 짜증
- 시에스타 기본
- Re:Station 외관
- 바 내부 배경

그 외는 후순위다.

## 9. 최종 검수 질문

새 대사를 추가할 때 아래 질문으로 검수한다.

1. 이 문장은 상담원도 할 수 있는 말인가?
2. 이 문장은 카루아가 문제를 해결하려 하는가?
3. 이 문장은 관찰에서 출발하는가?
4. 이 문장은 시에스타의 경험에서 나온 말처럼 들리는가?
5. 추천 결과가 없어도 이 문장이 살아있는가?

하나라도 틀리면 재검토한다.
